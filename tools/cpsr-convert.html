Convertisseur SNR - CPSR

Sessions enregistrées WinAPE (.snr) au format CPSR (CPC Power Session Replay, spécification v0.2), synchronisé sur les interruptions Gate Array de la machine émulée. Outil autonome : aucune dépendance, aucun accès réseau, fonctionne depuis un fichier local. Déposez un .cpsr pour le vérifier. Cf. SPEC.md dans le dépôt.

Déposez ici les fichiers
(ou utilisez le sélecteur ci-dessous) :

.snr : session à convertir  /  .cpsr : session à vérifier
.dsk, .ipf, .hfe, .raw (CTRAW), .cpr, .xpr, .cdt, .csw, .wav : médias référencés par la session (facultatifs, reconnus par nom)
